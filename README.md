# Zeus CLI

Zeus is an interactive, stylish OSS CLI agent focused on local-model workflows (Ollama-first), web research, structured outputs, content generation, and user-extensible skills/tools.

## Status

Zeus is pre-1.0 and actively evolving. The core CLI, local setup, search adapters, skills/tools manifests, and safety checks are in place.

## Features

- `ask`: Prompt local LLM via Ollama adapter
- `search`: Web search through pluggable providers
- `contacts find`: Parse LinkedIn CSV/URLs with filters
- `content blog` and `content hook`: SEO/social generation with voice profiles
- `research`: Source + synthesize software research summaries
- `skill` and `tool`: create/install/list/remove/validate dynamic capabilities

## Quickstart

From source:

```bash
npm install
npm run build
npm link
zeus init
zeus
```

After Zeus is published to npm:

```bash
npm install -g zeus-cli
zeus init
zeus
```

Command mode is still available for scripts:

```bash
zeus --help
zeus search "local AI agents" --format json
```

For development:

```bash
npm test
npm run verify
npm run start -- --help
```

`npm run verify` runs typecheck, tests, and the production bundle.

## Configuration

`zeus init` creates:

- `~/.zeus/config.json`
- `~/.zeus/skills/`
- `~/.zeus/tools/`
- `~/.zeus/voices.json`

Zeus works with Ollama by default:

```bash
export OLLAMA_BASE_URL=http://localhost:11434
export OLLAMA_MODEL=llama3.2
```

Search provider selection:

```bash
zeus search "local AI agents" --provider auto
zeus search "local AI agents" --provider duckduckgo
```

Optional API-backed search:

```bash
export BRAVE_API_KEY=...
export SERPAPI_API_KEY=...
export ZEUS_SEARCH_PROVIDER=auto
```

`auto` tries Brave, then SerpAPI, then DuckDuckGo.

## Extensibility

Zeus uses a hybrid model:

- Skills: declarative workflows + prompt/tool orchestration
- Tools: executable integrations with safety policies

Registries are local under:

- `~/.zeus/skills`
- `~/.zeus/tools`
- `~/.zeus/voices.json`

## Contributing

Start with `CONTRIBUTING.md`, run `npm run verify`, and keep changes focused. Security issues should follow `SECURITY.md`.

## Safety

Tool execution is safe-by-default. Tool manifests are strictly validated before install, readonly tools are checked for mutating commands, and shell inputs are quoted before interpolation.

## Release Readiness

The package entrypoint is `dist/cli.js`, generated by `npm run build`. Published packages include only `dist`, `README.md`, and `LICENSE`.
