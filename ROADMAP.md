# Roadmap

Zeus is starting as a local-first CLI agent. The roadmap favors a reliable core before marketplace or UI expansion.

## Near Term

- Improve interactive mode with command history and richer prompts.
- Add config loading from `~/.zeus/config.json` across all adapters.
- Add GitHub-based `skill install` and `tool install` flows.
- Add examples for common SEO, research, and contact workflows.
- Add release automation after the public repository is created.

## Later

- Homebrew distribution.
- Standalone binaries for users without Node installed.
- Optional local web UI.
- Skill/tool registry index.
- More model providers behind the inference adapter.

## Not Planned for v1

- LinkedIn scraping or browser automation for contact discovery.
- Cloud-hosted user accounts.
- Centralized telemetry by default.
