# Support

Zeus is an early open-source project.

## Getting Help

- Use GitHub Discussions for ideas, setup help, and design questions once the repository is published.
- Use GitHub Issues for reproducible bugs and small feature requests.
- Include your Node version, OS, Zeus version, command used, and relevant error output.

## Before Opening an Issue

```bash
node --version
npm --version
npm run verify
zeus --help
```

Please remove secrets, API keys, private contact data, and local file paths you do not want to share.
