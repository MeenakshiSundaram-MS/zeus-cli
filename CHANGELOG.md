# Changelog

All notable changes to Zeus will be documented here.

This project follows semantic versioning after `1.0.0`. Until then, minor versions may include breaking changes.

## 0.1.0 - Unreleased

### Added

- Local-first Zeus CLI with command and interactive modes.
- `zeus init` local workspace bootstrap.
- Ollama inference adapter.
- Pluggable search providers for DuckDuckGo, Brave, and SerpAPI.
- LinkedIn contact parsing from user-provided CSV/profile URLs.
- SEO blog and social hook generation with reusable voice profiles.
- Research pipeline with query decomposition, search, synthesis, and citations.
- Skill and tool manifest validation with Ajv.
- Safe-by-default tool runtime with shell input quoting.
- Typecheck, test, build, and package verification pipeline.
