## [0.1.0](https://github.com/MeenakshiSundaram-MS/zeus-cli/releases/tag/v0.1.0) - 2026-04-24

### Features

* local-first Zeus CLI with command and interactive modes
* `zeus init` workspace bootstrap with `~/.zeus/` config, skills, tools, voices
* `zeus doctor` — health check for Ollama, config, and search providers
* `zeus ask` — prompt local LLM via Ollama adapter with actionable connection error messages
* `zeus search` — web search via DuckDuckGo (built-in), Brave, and SerpAPI
* `zeus research` — question decomposition, multi-query search, synthesis with citations
* `zeus content blog` and `zeus content hook` — SEO/social generation with voice profiles
* `zeus contacts find` — parse LinkedIn CSV exports or profile URLs with filters
* `zeus skill` and `zeus tool` — create, install, validate, list, remove dynamic capabilities
* pluggable search provider factory with auto-fallback (`auto` → Brave → SerpAPI → DuckDuckGo)
* safe-by-default tool runtime: shell inputs quoted before interpolation, readonly checks
* first-run guard on LLM commands with `run: zeus init` guidance
* improved interactive shell banner with initialization hint
* full verify pipeline: typecheck + 33 tests + build on every publish
